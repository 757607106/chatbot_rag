# 钱流管理

## 1.云辉煌钱流管理简介

钱流管理是指企业为达到既定目标进行的筹集资金和运用资金的业务；日常业务涉及固定资产管理、收入费用管理、现金银行账户资金管理、债务管理。

## 2.云辉煌钱流管理业务介绍

单据:钱流管理提供了7类单据，处理费用业务做一般费用单和现金费用单；处理收入业务做其它收入单 ；处理现金银行卡存取可以做提现存现转账业务；处理长期待摊费用做待摊费用管理；增加减少单位应收应付金额做调账业务；调整会计科目金额可以做会计凭证。

报表：对外针对往来单位单位提供多维度的数据分析，包括单位应收应付、单位回款、账龄分析，对内分析内部职员、部门应收应付回款数据，现金银行、利润表、资产负债表、费用报表多方面多角度展现内部资金管控和运营情况。

### 3.6调账业务

简介：调整业务指的是会计处理的一个内容，即调整账务以达到预期的或规定结果的过程。例如因供应商企业倒闭无需再支付应付款，因客户企业倒闭导致应收款无法收回。调账业务单据包括：应收款减少、应收款增加、应付款增加、应付款减少、资金增加、资金减少。前四种调账针对往来单位，资金调账是内部调账

## 4.云辉煌钱流管理报表介绍

### 4.1应收应付

#### 4.1.1单位应收应付

用途：单位应收应付，统计了企业与其他单位之间的欠款数据，哪些单位还差本单位多少钱，本单位还欠哪些单位多少钱，从而企业即时处理好应收应付，做好各种准备。

报表路径：钱流管理—应收应付—单位应收应付

![图片 17](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8oLl952PdrZM0lap/img/346e7c89-01dd-4de7-a7db-a678768ced85.png)

_图 855 图片描述_

操作按钮说明：

1.过滤：点开后里面有五个选项，分别为：【显示全部】、【应收或应付不为零】、【只显示应收不为零】、【只显示应付不为零】、【预收或预付不为零】。

2.查询条件：可设置单位全名、地区全名作为报表查询条件，即选择我们要查询哪个单位和哪个地区的单位的应收应付。

3.列表：可以选择全部列表和部分列表，全部列表就是显示所有具体的单位信息，不包含单位类别的名称。例如a类单位中存在单位1，单位2，单位3；b类单位中存在单位4和单位5，全部列表即展示为单位1，单位2，单位3，单位4，单位5。部分列表则是展开某一个类别下面的具体单位，比如选中b类单位点击部分列表，则显示为单位4，单位5。

.4明细账本：可选择查询应收明细或应付明细，查询统计出某一时间段针对某一单位的每一笔影响应收应付的业务单据。

5.往来对账：根据当前选中的往来单位作为查询条件，跳转到往来对账报表，可查询出某一段时间影响应收应付的每一笔业务的对账况等。

报表字段说明： 

1.应收余额：指的是企业应收而未收到的款项余额，这些款项通常来源于销售商品后，客户尚未支付的金额。

2.应付余额：指的是企业应付而未支付的款项余额，这些款项通常是因为企业购买商品后，尚未向供应商支付的金额。

3.预收余额：指的是企业已经提前收取但尚未确认收入的款项余额。这些款项通常是企业在销售商品前，根据客户的要求或合同约定而预先收取的定金或预付款。

4.预付余额：指的是企业已经提前支付但尚未获得商品的款项余额。这些款项通常是因为企业需要向供应商预先支付一部分款项以确保商品的供应。

注意：以上数据都是包含了期初应收应付的，其中应收余额与应付余额是互相冲抵的，预收余额和预付余额也是互相冲抵的，显示的都是冲抵后的数据，冲抵之后，哪边还有数据就显示在哪边；

10、销售退货\_赠品金额：统计商品在销售退货单类单据（销售退货单、销售换货换入）单据里面赠品的销售退货成本金额

2.  此前应付：统计该单位在查询时间范围之前的应付数据，该数值也是与此前应收冲抵后的数据。
    
3.  进货应付合计：统计查询时间范围内的进货单产生的应付数据；当时直接在进货单上结算付款了的数据也是会统计在这里面的，即使当时进货单未付款但后面做付款单单独结算付款了该单据，这个字段还是会统计该数据的。若显示为负数，一般是做了进货退货单或者是在做进货单的时候填写的优惠金额大于了整单的金额。
    
4.  进货运费：查询时间范围内的进货单上填写的运费将会统计在此处。具体是统计到哪个往来单位上的，是根据进货单上填写的【运费往来单位】为准。
    
5.  销售运费：查询时间范围内的销售单上填写的运费将会统计在此处（销售单上选择的运费类型无论是代付或包送，都会统计进来）。具体是统计到哪个往来单位上的，是根据销售单上填写的【运费往来单位】为准。
    
6.  付款金额：统计查询时间范围内直接在进货类单据上付款给该往来单位的款项（包括付款给该运费往来单位的款项）以及单独做付款单付款给此单位的款项，但不统计使用预付账款账户来付款时的数据，也不包括使用一般费用单支付的款项。
    
7.  销售应收合计：统计查询时间范围内的销售单产生的应收数据；当时直接在销售单上结算收款了的数据也是会统计在这里面的，即使当时销售单未收款但后面做收款单单独结算收款了该单据，这个字段还是会统计该数据的。若显示为负数，一般是做了销售退货单或者是在做销售单的时候填写的优惠金额大于了整单的金额。
    
8.  销售代付运费：单独统计查询时间范围内的销售单上运费类型选择为【代付】的运费数据。具体是统计到哪个往来单位上的，是根据销售单上的【购买单位】为准。
    
9.  回款金额：统计查询时间范围内直接在销售单单据上收款的款项以及单独做收款单从此单位收款的款项，但不统计使用预收账款账户来收款时的数据，也不统计通过一般收入单收款的数据。
    
10.  应收余额：统计截止到查询时间结束日期时，该往来单位的应收余额，此处统计逻辑与单位应收应付类似，也是应收应付互相冲抵之后的数据，且冲抵后哪边还有数据就显示在哪边。
    
11.  应付余额：统计截止到查询时间结束日期时，该往来单位的应付余额，此处统计逻辑与单位应收应付类似，也是应收应付互相冲抵之后的数据，且冲抵后哪边还有数据就显示在哪边。
    
12.  应收上限：显示该往来单位设置的应收款上限数值，该数值可在基本信息---单位信息中设置，也可通过往来对账报表中的【修改限额】功能来设置。
    
13.  应付上限：显示该往来单位设置的应付款上限数值，该数值可在基本信息---单位信息中设置，也可通过往来对账报表中的【修改限额】功能来设置。
    
14.  预收余额：统计截止到查询时间结束日期时，该往来单位的预收余额，此处统计逻辑与单位应收应付类似，也是预收预付互相冲抵之后的数据，且冲抵后哪边还有数据就显示在哪边。
    
15.  预付余额：统计截止到查询时间结束日期时，该往来单位的预付余额，此处统计逻辑与单位应收应付类似，也是预收预付互相冲抵之后的数据，且冲抵后哪边还有数据就显示在哪边。
    
16.  应收越限：如果该往来单位当前实时的应收余额超过设置的应收上限限额，在“应收越限”单元格中有“√”，表示已经超出设置的限额。
    
17.  应付越限：如果该往来单位当前实时的应付余额超过设置的应付上限限额，在“应付越限”单元格中有“√”，表示已经超出设置的限额。

## 5云辉煌钱流管理常见问题

### 5.1问题描述：如何增加预收账款和预付账款

处理方法：

增加预收：做收款单，科目全名选择现金或银行，填上金额，然后点击一下左下角的【预收账款】的按钮，再将收款单过账，过账后金额会挂到预收账款中。做销售单的时候便可以使用预收账款进行结算。

增加预付：做付款单，科目全名选择现金或银行 ，填上金额，然后点击一下左下角的【预付账款】的按钮，再将付款单过账，过账后金额会挂到预付账款中。做进货单的时候便可以使用预付账款进行结算。

预收抵消：

收款单中，上表体选择预收账款 输入金额是抵冲预收账款；左下角点击了预收账款是增加预收账款；收款单上表体选择预收账款，再点击左下角的预收账款，那么不会增加预收账款也不会减少预收账款，相互抵消。

### 5.2问题描述：如何减少预收账款和预付账款，能不能直接删除预收账款，删除预付账款。

处理方法：

无法直接删除预收账款金额和预付账款金额，可以做单据减少预收账款、减少预付账款

减少预收账款（退回预收款）：

1、做付款单，选择对应单位，上表体科目选择现金/银行，输入金额后点击左下角【预付账款】，即可冲抵预收余额。

 2、做销售单，选择对应单位，左下角付款账户选择预收账款，输入金额过账，即可冲抵预收余额。

减少预付账款（退回预付款）：

1、做收款单，选择对应单位，上表体科目选择现金/银行，输入金额后点击左下角【预收账款】，即可冲抵预付余额。

2、做进货单，选择对应单位，左下角付款账户选择预付账款，输入金额过账，即可冲抵预付余额。

### 5.3问题描述：云辉煌哪个报表可以看未收款的销售单

处理方法：钱流管理--结算查询--按单结算查询---看【余额】字段，余额为0表示结算完成，不为0表示未结算完

### 5.4 问题描述：云辉煌如何查单个门店利润？

✅ 处理方案：云辉煌没有门店功能，没有门店利润报表；如果客户涉及到多个门店开单，建议用部门来区分，然后查询部门利润表（钱流管理--部门利润表）

### 5.5问题描述：现金银行明细账如何全部导出

### 5.12问题描述：往来对账的组号设置是什么意思，有什么用

✅ 处理方案：在往来对账报表中，可以对业务单据进行分组，即将需要的单据编成一组，可以统计组内余额，以达到方便对账的功能。点击“组号设置”按钮后，可以对选中的单据设置组号，组号可输入任意数字分组后，勾选报表表头的“组号排序”功能后，不同组的单据将按不同的颜色显示出来，以便于区分。同时，会显示组内余额，组内余额是统计组内单据应收款的余额。

### 5.13问题描述：职员应收应付里的应付发生额是如何产生的

✅ 处理方案：职员应收应付报表中应收应付发生额统计的是（查询时间段内该职员所涉及到的单据中应收金额和应付金额的总和合计值，例如查询时间段内销售单等其它单据共产生了1000应收金额增加，查询时间段内又收付款单据等其它单据又产生了400应收金额减少，则合计值为600。）可通过往来对账查看应收增加和应收减少明细，差值则为合计值。

### 5.14问题描述：云辉煌如何做固定资产增加？

✅ 处理方案：1；基本信息-会计科目--资产类--固定资产合计--增加固定资产，比如电脑。

2：购置固定资产/固定资产增加：钱流管理--会计凭证--借方：固定资产-电脑 贷方：现金/银行科目。

3：查询固定资产：钱流管理——资产负债表（树形表）找到对应的固定资产科目，查看本月发生额/累计金额以及科目明细。

### 5.15问题描述：云辉煌有没有其他应收款科目，怎么处理其他应收款科目数据

✅ 处理方案：云辉煌还没有单独的其他应收款科目，变通处理方法如下：

1.新建科目：在基本信息——会计科目——资产类 新建一科目名称为其他应收款的科目

2.数据录入：新建的其他应收款科目无法做收款单和付款单，科目数据录入到钱流管理——会计凭证里面

3.报表查询：其他应收款科目的数据和明细在钱流管理——资产负债表（树形表）可以查看下科目，点击左下角的明细账本可以查看到其应收款的会计凭证单据明细。

### 5.16问题描述：云辉煌有没有其他应付款科目，怎么处理其他应付款科目数据

### 5.17问题描述：资产负债表中的实收资本是如何产生的？

✅ 处理方案：

1、期初开账时，期初财务数据不满足等式：【资产=负债+所有者权益】，不平衡时会将差额计入到实收资本；

2、做年结存时，选择了将上一年的利润结转到实收资本里；

3、做会计凭证时选了实收资本这个科目；
